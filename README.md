# 概率论与数理统计：课程目录与学习安排

这套讲义按“现实问题 → 随机模型 → 概率分布 → 数字特征 → 极限定理 → 统计推断”的顺序组织。从第 31 课开始，按[教学规范](教学规范.md)逐课调整：先讲为什么需要这个概念，再建立直觉、解释定义和符号，最后逐步推导与应用。

数学工具在用到时回顾，不能默认读者理解求和、平方展开或标准化的中间步骤。后续涉及导数、积分时，也要先说明操作含义。第 36 课的矩母函数说明，以及第 38 课使用矩阵与多元变换的证明，已标为选读。

## 学习节奏与阶段检查

- 第 1—12 课：能从题目明确试验、随机变量与所求事件，分清 PMF、PDF、CDF。
- 第 13—24 课：能根据生成机制选择分布，并说明参数、期望和方差的含义。
- 第 25—32 课：能处理联合、边缘、条件与函数分布，区分大数定律和中心极限定理。
- 第 33—41 课：能区分参数、统计量、估计量和估计值，说明估计方法的依据。
- 第 42—49 课：先确认数据设计与适用条件，再选择区间或检验，正确解释结果。
- 第 50—52 课：能写出模型假设、完成计算，并报告结论及其适用范围。

建议每课先独立完成理解检查，再看参考答案；计算课可以拆成“概念与推导”和“例题与练习”两次学习。课次是内容单元，不对应固定的日历日期或学时。

## 本仓库的讲义编写约定

教学顺序、提问方式和逐课核验以[教学规范](教学规范.md)为准。以下保留数学与文件格式方面的约定。

1. **交代研究对象。** 说明一次试验做什么、随机变量记录什么、已知量和未知量各是什么。
2. **保持知识衔接。** 新概念先解释再使用；提前出现的知识注明回看课次。课末说明下一课解决的问题。
3. **定义与条件一起写。** 区分充分条件与必要条件、精确结论与近似结论、随机变量与其观测值。
4. **保留推导。** 关键公式说明从哪里来；使用未证明的定理时，避免把直觉或标准化计算当作证明。
5. **例题可以复核。** 写清数据、参数、计算步骤和结论；合成数据明确标注，近似值写明近似。
6. **练习有反馈。** 新增讲义包含理解检查和参考答案，覆盖概念辨析、计算及适用条件。
7. **统一记号。** 用 $X_i$ 表示随机观测，$x_i$ 表示观测值；$S^2$ 表示分母为 $n-1$ 的样本方差；用于矩估计的二阶样本中心矩使用分母 $n$。
8. **统一分位数方向。** 对本课程使用的连续分布，$q_p$ 指下尾分位数，即 $P(T\le q_p)=p$；$z_p$、$t_{\nu,p}$ 等沿用此约定。
9. **统一公式与引用。** 行内公式使用 `$...$`，独立公式使用 `$$...$$`；课程互引使用相对文件链接，清理平台专用引用标记和编辑对话。
